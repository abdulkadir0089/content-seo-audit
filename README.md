# Content & On-Page SEO Audit for a Psychology Blog

> **Case study** · SEO audit · Client: psychologist's personal blog (name kept private)

## Scope
Read and audited every URL in the site's sitemaps: **27 blog posts and 8 pages**,
checked against the author's own expertise and content categories.

## Findings, in priority order

### 1. Quick fixes (about 1–2 hours)
- An empty post that was indexed
- A homepage link to a category URL that returned 404
- A placeholder page with sample text that was indexed
- Past events still listed as "upcoming", with conflicting times
- Typos and factual errors inside posts, including one in an SEO title
- Paragraphs repeated within two posts
- Menu categories with no posts

### 2. Site-wide priorities
- **Internal links:** 26 of 27 posts had none. Proposed 6 topic clusters so each post links to 3–4 related ones
- **Titles:** 10 over 60 characters (one at 199) and four different brand suffixes in use
- **Meta descriptions:** about 14 were auto-pulled excerpts, quotes or missing
- **Headings:** long posts (up to 2,600 words) with no H2s
- **Trust (E-E-A-T):** health content is held to a higher standard, so recommended an author box
  with credentials, linked sources, citations for health claims and images in posts

### 3. Technical
- A German post served as English: fix the language tag and add hreflang to its English version
- An archive page and a signup page that should not be indexed
- Two H1s and a duplicated block on the homepage
- A possible duplicate terms page
- Article schema on pages that should use page schema types
- A hosting bot check that could block crawlers, to verify in Search Console

### 4. Post-by-post table
One main fix for each of the 27 posts.

### 5. New content plan
16 new topic ideas drawn from the author's talks and radio appearances, clinical specialties and empty categories.

## Deliverables
- Full audit report
- A before/after fix log with screenshots, prepared as a proposal for client approval

## Tools
WordPress · Rank Math · Google Search Console · sitemap analysis
